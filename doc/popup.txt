*popup.txt*  Vim-style popups and shared float components

Port of the nvim-lua/popup.nvim API (MIT, TJ DeVries) plus float, key-legend
and list-menu modules. See README.md for every option.

                                                                 *popup.create()*
popup.create({what}, {vim_options})
    Open a popup. {what} is a string, a list of lines, or a buffer number.
    Returns the window id and { win_id, bufnr }.

popup.move({win}, {vim_options})      Move or resize a popup.
popup.close({win}, {result})          Close it and run its callbacks.
popup.clear()                         Close every popup made by create().
popup.hide({win}) / popup.show({win})
popup.settext({win}, {text})
popup.getpos({win})                   line, col, width, height, visible

                                                                 *popup.confirm*
require("popup.confirm").open({opts})
    Small modal. {opts}: title, lines (chunks per line), choices
    ({ key, label, value, danger?, remember_key? }), on_choice(value, info),
    footer (chunks), footer_pos ("left"|"center"|"right"), hl, winhl.
    {info}.remember is true only for a remember key.
    menu = true makes the choices rows: j/k move (clamped, no wrap, other
    motions are put back), <CR> answers with the selected row, {default} is
    the starting index, {remember_keys} (like { "<S-CR>" }) answer the
    selected row with remember = true. Highlight: PopupSelect.

                                                                 *popup.legend.footer()*
legend.footer({entries}, {opts})
    Chunks and display width for a one-line key legend in a float footer:
    " key desc  key desc ". {entries} are { key, desc }; {opts}.key_hl and
    {opts}.desc_hl default to PopupKey and PopupFooter.
